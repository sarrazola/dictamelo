# Dictámelo 0.5.1

Available for macOS Apple Silicon, Windows Intel/AMD x64 and Windows ARM64.

- A clearer Mac installer: Retina artwork, large app and Applications icons, a drag arrow and installation instructions.
- Finder layout is generated without requesting Finder Automation permission. The app keeps its Developer ID signature and notarization through packaging.
- All three installers use the same versioned application source. Existing settings, personal API keys, accounts, Pro licenses and usage are preserved.

Free Cloud remains **30 minutes per week**, with AI cleanup included. Pro remains **180 hours per rolling 30 days**. Groq is the visible provider for new personal-key setup, with Whisper Large v3 recommended; hosted transcription continues to use Turbo.

Google OAuth is External / In production, and its branding is verified and published. Resend confirmation and password recovery email delivery has been verified. These hosted changes also apply to 0.5.0; signup abuse controls and paid lifecycle verification remain documented launch follow-ups. The proposed seven-day trial stays disabled.

Mac releases are Developer ID signed, notarized and stapled. Windows installers have Tauri updater signatures, but do not have Microsoft Authenticode certificates. Windows x64 testing under ARM emulation is distinct from physical Intel/AMD hardware testing. Intel Macs and 32-bit Windows installers are not provided.

See the [verification record](https://github.com/sarrazola/dictamelo/blob/main/docs/TESTING.md) and [production readiness](https://github.com/sarrazola/dictamelo/blob/main/docs/PRODUCTION_READINESS.md) for the exact completed checks and remaining limitations.
