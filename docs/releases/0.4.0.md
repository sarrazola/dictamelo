# Dictámelo 0.4.0

Release candidate for macOS Apple Silicon, Windows Intel/AMD x64 and Windows ARM64.

- Three clear choices: free with your own API keys, Free Cloud with 2,000 words per week, and Pro with 60 hours per rolling 30 days.
- AI cleanup included with Free Cloud transcription; words are counted once. Optional cleanup also applies to uploaded audio, with the original text preserved if cleanup fails.
- Email/password account screens, Google browser sign-in, visible usage and a repeatable Onboarding wizard.
- A minimum settings-window size and Check for Updates in the Mac application menu and tray.
- Cached noninteractive macOS credential access, with separate development and release namespaces.
- An attributed English speech fixture and regression checks before release builds.
- Local-path audio import and recovery when the system file dialog cannot open.

Cloud access is still in preview: Google accepts permitted test users, production confirmation/recovery email delivery is pending, and the proposed seven-day Pro trial is disabled. Personal-key mode does not require a Dictámelo account. See [production readiness](https://github.com/sarrazola/dictamelo/blob/main/docs/PRODUCTION_READINESS.md) and [actual verification results](https://github.com/sarrazola/dictamelo/blob/main/docs/TESTING.md).

The Windows installers use Tauri updater signatures; they do not have a Microsoft Authenticode certificate. Windows tests execute on native x64 CI; ARM64 is cross-compiled. The Windows VM was unavailable for this candidate's installation test. Intel Macs and 32-bit Windows are not supported.

On the test Mac, an operating-system file-provider blockage prevented the native picker and reading from Downloads. Importing a local copy by path passed transcription and cleanup. The app recovers from failed panel creation, but does not repair the underlying macOS service.

This candidate does not replace the stable automatic-update channel. Installers become immutable when this release is published.
