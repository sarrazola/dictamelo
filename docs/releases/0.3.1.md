# Dictámelo 0.3.1 — Mac preview

**This is a local Mac preview, not a public GitHub release.** Public 0.1.2 and draft 0.2.0 assets and updater manifests remain unchanged. No Windows build or 0.3.1 GitHub release is planned for this iteration.

## Changes

- Add **Check for Updates…** to the tray and native Mac application menu. The action opens the existing update screen, displays the check result and leaves downloading/installing to the user's explicit action.
- Cache native runtime credentials, suppress interactive macOS Keychain access, and separate release/debug namespaces. Release builds can silently migrate accessible old entries. Explicit deletion markers prevent old credentials or sessions from returning after deletion or logout.
- Retain OS-backed storage for personal provider keys, account sessions and existing Pro licenses. SQLite is not used as an unencrypted replacement. See [Local credentials](../LOCAL_CREDENTIALS.md) for the implementation and migration behavior.
- Configure Google login through Supabase, keeping the Google client secret server-side. The three plans remain personal keys without an account, Free Cloud with 2,000 words/week, and Pro with 60 hours per rolling 30 days.

## Verified

The signed/notarized preview is installed on an Apple M4 Max Mac running macOS 26.5.2. A permitted owned Google account completed browser sign-in and returned to the installed app. The session survived quitting and reopening; the final installed app displayed the correct account and 0/2,000-word usage without a Keychain prompt. The existing personal Groq key was also detected without prompting.

The Rust suite passed 55 tests, including synthetic native Keychain persistence, update, deletion, noninteractive-policy and debug-isolation checks. Final-source strict Clippy, seven Python configuration tests and JavaScript syntax checks passed. See [Testing](../TESTING.md) for the distinction between native API, mock-store and installed-candidate evidence.

The app and DMG passed Apple notarization, stapling and Gatekeeper. The installed executable matches the read-only DMG and reports version 0.3.1. Its 4,928,226-byte updater archive passed signature verification.

Clicking **Check for Updates…** in the native application menu opened the update screen, showed the check in progress and then the current-version result without installing anything. The tray shares that menu item in source, but its icon was not separately clicked in native UI verification. This local check does not publish an update or test downloading a newer release.

## External setup still pending

- Google audience remains **Testing** and supports permitted test users. Production publishing is blocked by incomplete branding. A real product homepage and privacy-policy URL are still needed; the current `dictamelo.com` response leads to a parked/lander page.
- SMTP has no host configured. Actual confirmation/recovery inbox delivery is unverified, although the earlier Auth API contract tests passed.
- The seven-day trial remains unavailable: the checkout has no trial and the app flag stays false until checkout, immediate access, cancellation and expiry are tested.

No Google client secret or exported JSON credentials were added to the desktop app or repository.
