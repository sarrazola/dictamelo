# Dictámelo 0.5.0

Release candidate for macOS Apple Silicon, Windows Intel/AMD x64 and Windows ARM64.

- Setup appears only on the first launch, with **Skip** on every step. Existing settings are preserved.
- Provider and model share one row. New setup exposes Groq and recommends **Whisper Large v3** for personal keys; existing provider configurations remain supported.
- Mac Settings stay open across application switching. Closing the window returns Dictámelo to the menu bar.
- **Free Cloud: 30 minutes per week. Pro: 180 hours per rolling 30 days.** Usage is shared across devices. AI cleanup is included and adds no audio time.
- Preserve existing licenses, account sessions and historical usage. Enforce Free audio reservations and strengthen billing-table access controls.
- Extend the licensed English speech regression with exact audio-time accounting, concurrent requests and quota boundaries.

Hosted transcription uses Whisper Large v3 Turbo. The Large v3 recommendation applies to personal keys. Free recordings remain limited to two minutes; the final accepted recording is delivered whole. Pro retains its ten-second minimum per transcription and ten-minute request limit. See [plan details](https://github.com/sarrazola/dictamelo#three-plans).

Cloud access remains in preview: Google accepts permitted test users, production confirmation/recovery email delivery is pending, and the proposed seven-day Pro trial is disabled. Personal-key mode does not require a Dictámelo account. See [production readiness](https://github.com/sarrazola/dictamelo/blob/main/docs/PRODUCTION_READINESS.md) and [actual verification results](https://github.com/sarrazola/dictamelo/blob/main/docs/TESTING.md).

Windows installers use Tauri updater signatures and do not have Microsoft Authenticode certificates. ARM emulation is not a physical Intel/AMD test. Intel Macs and 32-bit Windows installers are not provided.

This candidate does not replace the stable automatic-update channel. Published installer bytes are immutable.
