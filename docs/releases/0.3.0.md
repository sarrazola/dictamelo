# Dictámelo 0.3.0 — local Mac preview

**This is a tested local Apple Silicon preview, not a published public release.** The public 0.1.2 release and existing 0.2.0 draft assets remain unchanged. No Windows build, release asset or updater manifest was produced for this iteration.

## Changes

- Enforce a minimum window size of 960 × 680 and present three clear choices: Free with your own API keys, Free Cloud with 2,000 words/week, and Pro at $4.99/month with 60 hours per rolling 30 days.
- Add a visible, repeatable three-step Onboarding wizard for selecting a mode, configuring access and reviewing readiness.
- Add email/password signup and login, confirmation and password recovery, plus browser-based Google PKCE support. Google configuration and a live browser return remain pending.
- Preserve personal-key mode without a Dictámelo account and existing Pro licenses.
- Enforce paid quota reservations, a single active request per license, product ownership checks and 12,000 requests per rolling 30 days. Hosted models are Whisper Large v3 Turbo and GPT-OSS 20B; cleanup allows 3M input and 2M completion tokens in the same rolling window. Completion accounting includes reasoning.
- Compile the official edition from the same public source. Default source builds disable hosted services and automatic updates; explicit public metadata configures official or self-hosted builds.

## Verified

The preview was installed from its read-only DMG into `/Applications/Dictámelo.app` on an Apple M4 Max Mac running macOS 26.5.2. Apple accepted both the app and DMG; both were stapled, and signature/Gatekeeper checks also passed for the mounted and installed app. The updater archive signature passed independently against the embedded public key.

Checks included 48 Rust tests under default and official configuration, strict Clippy, seven Python configuration tests, six Deno backend tests, three opt-in live Groq tests, local and live transactional quota tests, and live access-control checks. Browser mock checks covered six languages without overflow at the minimum size. Native checks confirmed the size limit, three plans, wizard readiness and real transcription of a synthesized Spanish WAV selected through the file picker using the existing personal Groq key.

A live Supabase Auth API contract test passed confirmation, replay rejection, password login, refresh, recovery, logout and initial 0/2,000-word usage; its synthetic account was removed. That test did not send an email. See [the complete verification record](../TESTING.md) for scope and limitations.

## Still pending

- Production SMTP configuration and actual confirmation/recovery inbox delivery.
- Completion of Google Cloud setup/terms, provider enablement and native browser-return testing. No Google terms were accepted during this iteration.
- A seven-day trial's checkout, immediate access, cancellation and expiry. The checkout currently has no trial and the app's trial availability flag stays false.
- A fresh live paid-license cloud flow and physical spoken dictation through cursor paste on this Mac.

The local preview files are in `dist/v0.3.0-macos-preview/`: the DMG, updater archive, detached signature and `SHA256SUMS.txt`. Local installation and backend deployment do not publish a GitHub release or offer a new automatic update.
