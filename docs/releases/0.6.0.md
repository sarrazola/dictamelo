# Dictámelo 0.6.0

Mac development build; not published as a complete cross-platform release.

- Download speech models from inside the app and transcribe on the computer with Whisper, Canary Flash or Parakeet.
- Use Groq, OpenAI, Mistral or Deepgram with personal keys. Select cloud cleanup separately; local transcripts require explicit permission before any cloud cleanup.
- Manage verified model downloads, cancellations and deletion from a catalog designed for future model additions.
- Recognize providers by their bundled logos and enable launch at login by default on new installations.

Existing account, license, personal-key and startup preferences are preserved. The published 0.5.1 installers and updater manifest remain unchanged. Windows integration and testing are deferred until the Mac implementation is reviewed.

Build and native execution evidence belongs in [Testing](../TESTING.md); model formats, licenses and extension instructions are in [Local models](../LOCAL_MODELS.md).

Mac verification completed on Apple M4 Max: 93 Rust tests, 22 UI tests, real local audio and installed quit/restart checks. The local app and DMG are signed, notarized, stapled and Gatekeeper verified. Parakeet is the recommended local model; Canary has a documented Spanish accuracy limitation. The additional paid cloud providers have request-contract coverage and still need live test keys. See the verification record for exact test and platform boundaries.
