# Dictámelo 1.0.2 for macOS

- Use **Microsoft MAI-Transcribe-2** for dictation and imported audio. Open **Models → Your API keys → Microsoft Azure** and enter the endpoint and subscription key from your own Azure Speech resource. Dictámelo saves the key in macOS Keychain, and Azure bills usage to your account. See the [Azure setup guide](https://github.com/sarrazola/dictamelo/blob/v1.0.2/docs/CLOUD_PROVIDERS.md#microsoft-azure-setup).
- The five personal-key providers fit in one compact row, with a monochrome Microsoft icon.

On **Apple Silicon Macs**, choose **Check for Updates** in Dictámelo 1.0.1. For a first install or an upgrade from 1.0.0, download `Dictamelo_1.0.2_aarch64.dmg`, quit any running copy and drag Dictámelo into Applications. The app and installer are signed and notarized by Apple.

For Windows Intel/AMD and ARM64, use the [Windows 1.0.0 installers](https://github.com/sarrazola/dictamelo/releases/tag/v1.0.0).
