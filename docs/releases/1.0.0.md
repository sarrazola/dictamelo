# Dictámelo 1.0.0

- Download and run speech models on your computer: Whisper Tiny, Base, Small and Large v3, Canary 180M Flash and Parakeet v3.
- Browse models in a compact list with download progress, cancellation, selection, language controls and expandable details.
- Use Groq, OpenAI, Mistral or Deepgram with your own API key. Saved keys remain visibly masked, with explicit Change and Cancel actions.
- See your cloud plan, account actions, Free usage and renewal directly in Models. Selecting cloud without an account requires sign-in rather than silently using a stored personal key.
- Enable launch at login by default on new installations; preserve existing preferences, models, credentials, accounts and licenses on upgrade.

Local speech needs no account, provider key or hosted allowance after downloading a model. Optional AI cleanup uses a cloud provider; local transcripts are sent only after explicit consent. Local transcription never silently falls back to cloud.

Free Cloud includes 30 minutes per week and AI cleanup. Pro includes 180 hours per rolling 30 days. The seven-day trial remains disabled and Pro's detailed usage meter is not yet available in the client.

Choose the Mac DMG, Windows Intel/AMD x64 EXE or Windows ARM64 EXE for your computer. Platform-specific execution, signing and known limitations are recorded in [Testing](../TESTING.md) and [Windows verification](../WINDOWS_BUILD_REPORT.md). Canary has a documented Spanish accuracy limitation; Parakeet is recommended for local dictation. Additional personal-key providers have protocol regression coverage; live testing requires the corresponding provider account.
