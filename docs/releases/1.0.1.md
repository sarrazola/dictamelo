# Dictámelo 1.0.1 — macOS

Silent shortcut presses no longer need to reach a speech model. Dictámelo now checks microphone audio for voice locally before transcription, preventing the unwanted "gracias"/"thanks" output in the tested silence, low-noise and notification-sound cases. Rejected audio is not uploaded, does not consume cloud transcription quota and leaves history and the clipboard unchanged. Actual spoken words, including "gracias", are not blacklisted.

The Mac start sound now uses a short Tink cue instead of Pop, which could resemble a spoken syllable when picked up by the microphone.

This release also ships the Mac Fn shortcut, hold-to-talk or press-to-start/stop recording modes, a simpler shortcut editor, and the merged file-transcription/settings reliability fixes. Saved shortcuts, automatic paste, accounts, provider keys, local models and Pro licenses are preserved.

## Download and upgrade

- **Apple Silicon Mac:** download `Dictamelo_1.0.1_aarch64.dmg`, quit Dictámelo, and drag the app into Applications to replace the installed copy.
- The app and DMG are signed with Developer ID, notarized by Apple and stapled. The updater archive uses the existing signing key.
- **From 1.0.0:** install this DMG once. Version 1.0.1 uses `latest-macos.json` for subsequent Mac updates. The legacy shared manifest stays at 1.0.0 so Windows users are not offered a misleading update to their existing installer.
- **Windows remains at 1.0.0.** No Windows installer, build, VM session or Windows runtime test was produced for this release. Existing [Intel/AMD and ARM64 downloads](https://github.com/sarrazola/dictamelo/releases/tag/v1.0.0) remain available.
- Intel Mac installers are not provided.

See [Testing](https://github.com/sarrazola/dictamelo/blob/main/docs/TESTING.md) for the exact verification scope. Voice detection is a guard against non-speech, not a guarantee against every possible recognition error. Fn remains optional; choose a regular shortcut if you use Fn combinations while dictating.
