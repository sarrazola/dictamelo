# Version 0.2.0 release status

The release remains a draft until production email delivery is configured and verified. The code and backend are implemented; this is an external mail setup requirement, not a completed public launch.

## Verified

- macOS: 35 Rust tests, strict Clippy, a real Keychain read/write/delete round trip, and a clean tracked-source build passed.
- Backend: Deno checks/tests, transactional SQL quota tests, and live free-account authentication, transcription, usage accounting, quota rejection, and refresh passed. Test accounts were removed. The Auth test redeemed an admin-generated code without sending mail.
- macOS app and DMG: Developer ID signed, accepted by Apple, stapled, and accepted by Gatekeeper. Downloads from the GitHub draft matched local SHA-256 hashes; the contained app was version 0.2.0 and notarized. The updater archive retained the notarization ticket after extraction.
- Native Windows x64: [GitHub Actions run 33990373020](https://github.com/sarrazola/dictamelo/actions/runs/33990373020) passed 36 Rust tests and built the NSIS installer. The application payload's PE machine type was verified as `0x8664`. Its source commit was `4b06ee9`; application source/manifests matched the final macOS source.
- The native x64 installer was signed on the Mac with the existing Tauri updater key and uploaded to the draft. No private key was given to GitHub Actions.
