Permisos de macOS

Dictado necesita dos permisos: el micrófono para grabar tu voz y Accesibilidad para pulsar ⌘V en la app donde estás escribiendo. Nada se graba hasta que mantienes el atajo.

Micrófono Se pide la primera vez que grabas. Si lo negaste, actívalo en Ajustes del Sistema → Privacidad y seguridad → Micrófono.

Accesibilidad Permite a Dictado enviar la pulsación ⌘V. En Ajustes del Sistema → Privacidad y seguridad → Accesibilidad, activa «Dictado».
